# odin_recipes
The scope of the recipe project is to build a basic website that displays different types of recipes, three in this case, each accessible through a link element on the home page. 

Each individual recipe page must have:

. a h1 header for the recipe, "Odin Recipes",
. a link that take the user back to the home page,
. a free image of the finish dish,
. a description header followed by a descriptive paragraph or two of the recipe,
. an "Ingredients" header, followed by,
. an unordered list of the ingredients needed for the recipe,
. and finally, a "Steps" header, followed by,
. an ordered list of the steps needed for making the dish.
